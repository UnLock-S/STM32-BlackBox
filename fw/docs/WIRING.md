## 0. 供电与共地（先看这条）

| 事项 | 结论 |
|---|---|
| 主供电 | **J-Link 的 3V3 给板子供电**（当前）。板子与外设**必须共地** |
| 外设供电 | OLED / SD 卡座取 **3V3**（已实测） |
| ⚠ **需要 5V 的模块** | **C0832C（ADC0832）必须 5V**（TI 原厂 VCC **4.5–6.3 V**，绝对最大 6.5 V → **3.3 V 不工作**）<br>**CAN 收发器**的主电源也是 5V（见 2.3） |
| ⚠ 电平 | F103 是 3.3 V 器件。**非 FT 引脚直连 5 V 会损坏** —— 本工程用到的 5V 输入脚（PB15、PB8）**已查数据手册确认是 `I/O FT`（5 V 容忍）**，可直连 |

### 0.1 5V 从哪来（**本次必须解决**）

板子的 **5V 脚 = micro-USB 的 VBUS**（蓝板原理图已确认：USB1 → `5V` 网络，经 ME6211C33 出 3.3 V）。
所以：**把蓝板自己的 micro-USB 插到电脑**，板上的 `5V` 与 `3V3` 两个脚就都有了。

**推荐流程（单电源，无冲突）**
1. 蓝板 micro-USB 插电脑 → 万用表确认 `5V` 脚 ≈ 5.0 V、`3V3` 脚 ≈ 3.3 V
2. **把 J-Link 那根 3V3 线从板子上拔掉**，只留 SWDIO / SWCLK / GND 三根
3. 试烧写：能连上就继续；**若探针抱怨 VTref** 说明它要电平参考 → 再接回那根
   （J-Link 20 脚排线的 **1 脚 VTref 是"电平参考输入"**，不与板上 LDO 冲突；
   接的是 3.3 V **输出**脚才叫两路电源顶同一轨）
4. 两个模块的 5V 都从板子的 `5V` 脚取。**建议垫一块面包板做 5V/3V3/GND 汇流排**
   （杜邦线一拖二不好插，面包板不算焊接，符合"不焊接"原则）

**若不想插板子 USB**：也可用 FT232 板的 `5V`（它由 USB VBUS 供电）——
**但必须先用万用表量那个脚对 GND 确实是 ~5 V** 再接，且 FT232 的 VCCIO 跳线保持 **3.3 V**。

### 2.2 C0832C / ADC0832（位翻转驱动，非硬件 SPI）

**芯片**：`C0832C 1BK CSTR G4`，8 脚贴片焊在 DIP 8 脚转接板上，**无丝印**。
**引脚定义（TI 原厂 ADC0832-N，8 脚 DIP/SOIC 标准，已查数据手册确认）**：

| 芯片脚 | 名称 | 功能 | 接 MCU | main.h 标签 |
|---|---|---|---|---|
| **1** | CS | 片选，**低有效** | **PB12** | `C0832_CS_Pin` |
| **2** | CH0 | 模拟输入通道 0 | 待测电压 | — |
| **3** | CH1 | 模拟输入通道 1 | 待测电压 | — |
| **4** | GND | 地 | GND | — |
| **5** | **DI** | **数据输入**（MCU→芯片） | **PB14** | `C0832_DI_Pin` |
| **6** | **DO** | **数据输出**（芯片→MCU） | **PB15** | `C0832_DO_Pin` |
| **7** | CLK | 时钟输入 | **PB13** | `C0832_CLK_Pin` |
| **8** | VCC | 电源（**同时是内部基准 VREF**） | **5V** | — |

> ⚠ **5/6 不要接反**：`pin5 = DI`、`pin6 = DO`（DI 是芯片的输入，接 MCU 的输出脚 PB14）。
> 这颗芯片**没有独立 VREF 脚**，基准就是 VCC → 5 V 供电时量程 0–5 V、1 LSB = 5/256 ≈ **19.5 mV**。
>
> ⚠ **必须 5 V 供电**（4.5–6.3 V）；3.3 V 不工作。
> ⚠ **CH0/CH1 电压不得超过 VCC**（绝对最大 VCC+0.3 V）。
> ✅ 逻辑电平 VIH≥2.0 V / VIL≤0.8 V → **3.3 V 的 MCU 输出能可靠驱动它**；
> ✅ DO 输出摆到 ~VCC(≈5 V)，**PB15 是 `I/O FT`（5 V 容忍）→ 可直连，无需电平转换**。

#### 无丝印时怎么认 pin 1（**接 5V 前务必先做**）

1. **看封装标记**：贴片芯片的 **pin 1 由圆点/倒角**标出；DIP 转接板通常有**半圆缺口**。
2. **编号规则（缺口/圆点端朝上，从上往下看）**：**左上 = 1**，逆时针数 →
   左边一列自上而下 **1,2,3,4**，右边一列自下而上 **5,6,7,8**。
3. **结构性复核**：由此 **VCC(8) 与 GND(4) 在斜对角**。
4. **万用表复核**：二极管档测这两只斜对角脚，一个方向应看到 **~0.5–0.8 V 的结压降**，
   反向读数明显更大/不通。**两个方向读数一样或近似短路 → 认错了脚**。
5. **首次上电保护**：在 **5V 到 pin8 之间串一个 ~100 Ω** 电阻再上电，
   量电阻上的压降（正常只有几十 mV，芯片约 2.3 mA），并摸一下不发烫；
   确认无误后去掉电阻。

#### 引脚编号图示（贴片圆点 = pin 1，转接板 2×4 排针对应）

**判据（不用管圆点在哪一角，规则唯一）**：
- **圆点 = pin 1**；
- **圆点那一列**：从**圆点端**往另一端 = **1、2、3、4**；
- **对面那一列**：**与 pin 1 同一排的是 pin 8**，往另一端 = **8、7、6、5**；
- 因此 **pin 8(VCC) 与 pin 4(GND) 永远斜对角**；**pin 1(CS) 与 pin 5(DI) 永远斜对角**。

**接 5V 前的万用表复核（二极管档）**

| 测哪对 | 期望 |
|---|---|
| **pin4 ↔ pin8**（VCC/GND 那条对角线） | **只有一个方向有明显导通压降 ~0.5–0.8 V**，反向明显更大 |
| pin1 ↔ pin5（CS/DI 那条对角线） | 两个方向都基本不通/读数很高 |

两个方向读数一样或近似短路 → **脚认错了，别上 5V**。

#### 模拟输入测试源：滑动变阻器 / 电位器（**分压接法**）

3 脚电位器必须**三个脚都用**（两端 + 滑动端），接成**分压器**：

```
        左端                     中间脚(滑动端)            右端
  5V ────●──────── 176 Ω ──────────●────── 84 Ω ──────────●──── GND
                                    │
                                    └──────────────▶ C0832C pin2 (CH0)
```

| 电位器脚 | 接 | 说明 |
|---|---|---|
| 一端（与滑动端**阻值较小**的那端） | **GND** | 该端接 GND → 当前刻度读数小，拧动后单调增大 |
| 另一端 | **5V** | 用 5V 才能吃满量程（基准 = VCC = 5V） |
| **中间脚 = 滑动端** | **C0832C CH0** | 被测电压 |

> ⚠ **不能只用两端（2 线）**：那样只是可变电阻，没有确定电压，ADC 读数不可信。
> ADC 测的是电压，必须分压。

**怎么认出中间脚 = 滑动端**：万用表量两端 = 总阻；中间脚分别对两端的两次读数**之和 = 总阻**。

**读数公式与实测标定**：`code ≈ 255 × R(滑动端→GND) / R总`

实例（实测那颗：总阻 **257 Ω**，刻度 30% 时滑动端到右端 **84 Ω**）：
- V = 5 × 84/257 ≈ **1.63 V** → **code ≈ 83**（`adc` 期望 CH0 ≈ 83~85、CH1 = 0）
- 拧动刻度应 **0 → 255 连续平滑变化**；跳变/死区/到不了两端 = 时序问题

**注意**
- 电流 = 5 V / 257 Ω ≈ **19 mA**、功耗 ≈ 0.1 W。USB 5V 没问题，但**别用 0.05 W 级小微调电位器长期接**。
- 分压源阻抗最差为 R总/4 ≈ **64 Ω**，远低于 ADC0832 对源阻的 1 kΩ 要求 → 不会因源阻损失精度 ✅
- **基准就是 VCC**：本芯片无独立 VREF 脚，USB 5V 偏低会让所有读数按比例整体偏移（台架验证够用）。

#### 验证方法（比示波器更好用：**已知输入法**）

位翻转驱动没有硬件握手，但**不需要示波器也能判定对错**——喂一个已知电压即可：

- 把 **CH0 接到板子的 3V3**、**CH1 接 GND**
- 执行 `adc`，期望：**CH0 ≈ 165–172**（3.3 V / 5 V × 256 ≈ 169）、**CH1 = 0 ± 1**
- 若 CH0 明显不对（满量程/全 0/乱跳）→ 时序或 DI/DO 有问题，再上示波器查

**状态**：⬜ 待接线（时序本身仍需真机首测）。
**接完后的验证**：`adc`（按上面已知输入法）；整体再用 `test` 逐项自检。

### 2.3 CAN（CAN1 @1 Mbps，PB8/PB9 需 **引脚重映射**，配野火 SIT1042AQT 模块）

**野火模块引脚：`VIO`、`5V`、`GND`、`TXD`、`RXD`（无 CANH/CANL 引出则走板上端子）**

| 模块引脚 | 方向 | 接 | 说明 |
|---|---|---|---|
| **VIO** | 电源 | **板子 3V3** | ★★ **逻辑电平参考，必须接 3.3 V**。它的 TXD/RXD 电平跟随 VIO；<br>接 5 V 会让 RXD 输出 5 V（PB8 虽是 FT 能扛，但没必要冒险、也没必要） |
| **5V** | 电源 | **板子 5V** | 收发器主电源（**见 §0.1 的 5V 方案**） |
| **GND** | 地 | **GND** | 共地 |
| **TXD** | 输入（模块接收） | **PB9** | `CAN_TX`，MCU → 模块 |
| **RXD** | 输出（模块发送） | **PB8** | `CAN_RX`，模块 → MCU |

> PB8/PB9 的 CAN 功能是**重映射**功能（ST 数据手册 Table 5：默认 TIM4_CH3/CH4，
> 重映射为 `CANRX`/`CANTX`）——`.ioc` 已配 `CAN_Activate`，若将来手改配置别把重映射丢掉。

**配置**：1 Mbps，BS1=6 TQ / BS2=2 TQ / SJW=1 TQ / Prescaler=4 → 采样点 **77.8%**（CiA 301 推荐值）。
**CANH / CANL**：真总线两端各需 **120 Ω** 终端电阻；短距自测可先不加。

⚠ **单收发器不能做真总线测试**：普通模式下没有第二个节点回 ACK，
发送会不断重试并最终进入 bus-off。**只有一个模块时用回环模式自测**：

| 命令 | 用途 | 期望 |
|---|---|---|
| `can stat` | 看控制器状态/错误计数 | 初始化后 TEC/REC 接近 0 |
| **`can loop`** | **回环自测（不依赖外部 ACK）** | 自发自收成功、计数增加 |
| `can send 0x123 1122334455667788` | 发一帧（真总线需第二个节点） | 有 ACK 才成功 |
| `can bench` / `can stop` | 启动/停止周期发送 | 计数器变化 |
**注意**：CAN 引脚在 PB8/PB9 上**必须开 AF 重映射**，否则无输出（`.ioc` 已配）。

## 4. 接线检查清单（每次接完一个新模块照这个走）

1. **断电接线**，接完先目视核对：**VCC 电压**、**GND 共地**、**TX/RX 是否交叉**
2. 上电，先用 `fw/tools/sbb_serial.py` 打开串口确认固件还活着（有 `[mon]` 行）
3. 跑该模块的**探测类命令**（`oled scan` / `sd info` / `adc` / `can`）
4. 用 J-Link 读**该外设的寄存器现场**（`SR`/`CR`/`IDR`）—— 比猜快得多
5. 若"没反应"，先分责：**电气层 → 链路层 → 句柄层 → 驱动层 → 触发层 → 判读层**
   （六步顺序见 `docs/DEBUG-LOG.md` 的 Bug #6 结案与技能 `stm32cubemx-cli-ioc`）

## 5. I2C 上拉电阻加固（**通 SCL/SDA 各并 4.7kΩ 到 3V3**）

### 5.1 为什么必须加

OLED 模块自带的上拉实测 **SCL↔VCC = 9.84kΩ、SDA↔VCC = 9.90kΩ**（偏弱）
+ 本项目全程用长杜邦线 → 上升沿 t_r ≈ 1.3~2.1µs，超出 I2C 规范（100kHz 要求 ≤1.0µs）。
后果（本项目实际踩到过）：SCL 被误采样 → 面板 I2C 状态机逐步被打乱 →
**"能应答但时序退化/画面定格/完全不应答"** 三种故障都出现过。

**并联 4.7kΩ 后等效上拉 ≈ 3.2kΩ**（9.8k ∥ 4.7k），t_r 降到 ≈0.5~0.8µs，回到规范内。

### 5.2 接线（**只有两个电阻，无极性**）

| 电阻 | 一脚接 | 另一脚接 | 说明 |
|---|---|---|---|
| **R1 = 4.7kΩ** | **SCL**（模块 SCL 脚 / 蓝板 **PB6**）| **3V3** | 3.3V 上拉 |
| **R2 = 4.7kΩ** | **SDA**（模块 SDA 脚 / 蓝板 **PB7**）| **3V3** | 3.3V 上拉 |

```
        3V3 ──┬──────────────┬──── (蓝板 3V3 排针)
              │              │
            [4.7k]         [4.7k]         ← R1 / R2，无极性
              │              │
   OLED SCL ──┴──── PB6     │             ← 与原有杜邦线【并联】，不是串进去
   OLED SDA ────────────────┴──── PB7
   OLED VCC ────────────────── 3V3       ← 模块供电仍是 3V3（不动）
   OLED GND ────────────────── GND
```

**要点（错一个就不工作）**
- 两个电阻的**另一端都接 3V3** ✓
  - **绝不能接 GND** ✗（那是把总线直接拉死）
  - **绝不能接 5V** ✗（SSD1306 是 3.3V 器件，会经上拉灌 5V 进去）
- **并联，不是串联** ✓ —— 电阻只是给 SCL/SDA 加一条"到 3V3 的弱通路"，
  原有杜邦线一根都不动 ✓
- **蓝板的 3V3 与 GND 相邻，插之前看清丝印** ✗（这是最容易出错的一步）
- 断电插拔 ✓

### 5.3 怎么插（无焊接条件下）

- **推荐：插在一块小面包板上** —— 两个电阻插面包板，用杜邦线把电阻两端引到
  OLED 的 SCL/SDA 和蓝板的 3V3 ✓（最稳）
- **没面包板：把电阻引脚插进空余的杜邦母头里**（母头金属弹片能夹住电阻脚 ✓），
  或用两根备用杜邦线做"三通"✓
